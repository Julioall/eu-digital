# SPEC-009 — Aprendizagem incremental de padrões

Status: blocked
Fase: 4
Dependências: SPEC-008

## Objetivo
Descobrir recorrências e sequências sem catálogo de tarefas.

## Requisitos
- Clustering incremental.
- Suporte, estabilidade e recência.
- Detecção de mudança de conceito.
- Padrões versionados.
- Feedback positivo e negativo.

## Escopo negativo
Nomeação automática como verdade e execução de ações.

## Critérios de aceite
- [ ] Padrão só é promovido após suporte configurável.
- [ ] Correção humana altera confiança.
- [ ] Deriva gera nova versão ou divisão.
- [ ] Métricas de cluster são registradas.
