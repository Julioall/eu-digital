# Prompt inicial para Codex

Leia `AGENTS.md` e todos os documentos referenciados por ele.

Sua tarefa é implementar exclusivamente a SPEC indicada pelo usuário. Antes de modificar código:

1. verifique o status e as dependências;
2. leia os contratos e ADRs aplicáveis;
3. apresente uma análise curta de impacto;
4. identifique os testes que devem existir;
5. pare se houver conflito ou requisito arquitetural ausente.

Implemente o menor incremento que satisfaça todos os critérios de aceite. Não antecipe outras SPECs. Ao final, execute as validações, atualize a documentação afetada e crie um relatório com base em `templates/EXECUTION_REPORT.md`.
