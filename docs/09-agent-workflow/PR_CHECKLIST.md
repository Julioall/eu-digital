# Checklist de Pull Request

- [ ] Uma única SPEC principal.
- [ ] Dependências satisfeitas.
- [ ] Escopo negativo respeitado.
- [ ] Contratos versionados.
- [ ] Testes adicionados antes ou junto da implementação.
- [ ] Lint, tipos e testes passam.
- [ ] Nenhuma API externa adicionada.
- [ ] Nenhum modelo pesado concorrente.
- [ ] Documentação atualizada.
- [ ] Relatório anexado.
- [ ] Rollback descrito.
