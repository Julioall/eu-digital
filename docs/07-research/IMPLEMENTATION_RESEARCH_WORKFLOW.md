# Fluxo científico de implementação

## Camadas de evidência

1. plausibilidade teórica;
2. protótipo Python;
3. resultado experimental;
4. efeito causal por ablação;
5. reprodução;
6. equivalência C++;
7. desempenho operacional;
8. comportamento longitudinal;
9. promoção para runtime.

## Regra

Uma implementação C++ não valida uma hipótese científica por ser rápida. Uma implementação Python não se torna adequada para produção por apresentar bom resultado em um experimento curto.

A aprovação exige evidência científica e evidência de engenharia.
