# Controle de Mudanças

Toda mudança relevante deve ser classificada:

- correção;
- melhoria compatível;
- mudança de contrato;
- mudança arquitetural;
- mudança constitucional.

Mudanças de contrato exigem versionamento. Mudanças arquiteturais exigem ADR. Mudanças constitucionais exigem aprovação humana explícita.

Nenhuma SPEC concluída pode ser reaberta silenciosamente.
