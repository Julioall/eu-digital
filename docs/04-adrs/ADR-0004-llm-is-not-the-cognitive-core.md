# ADR-0004 — O LLM não é o núcleo cognitivo único

Status: aceito

## Decisão

O LLM é responsável por interpretação multimodal, linguagem, síntese e explicação. Memória, temporalidade, padrões, confiança, objetivos e modelo de si permanecem em componentes explícitos.

## Razão

Evitar dependência de contexto efêmero, alucinação como estado interno e impossibilidade de auditoria.
