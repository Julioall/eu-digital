# ADR-0002 — Execução local por padrão

Status: aceito

## Decisão

Todos os sensores, memórias, inferências e modelos pessoais devem rodar localmente. Integrações externas exigem novo ADR e consentimento explícito.

## Consequências

O projeto deve trabalhar com quantização, processamento sob demanda e limites rigorosos de memória.
