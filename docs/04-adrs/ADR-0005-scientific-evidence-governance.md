# ADR-0005 — Governança por evidência científica

Status: aceito

## Decisão

Mecanismos cognitivos devem seguir `docs/07-research/SCIENTIFIC_DECISION_POLICY.md`.

Toda SPEC cognitiva deve incluir hipótese, baseline, métrica, ablação e critério de falsificação.

## Consequência

Demonstrações visuais e respostas convincentes não bastam como evidência.
