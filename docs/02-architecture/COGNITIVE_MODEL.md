# Modelo Cognitivo Funcional

## Modelo de si

Representa:

- identidade operacional;
- sensores disponíveis;
- capacidades;
- limitações;
- estado de execução;
- confiança média;
- memórias relevantes;
- histórico de aprendizagem;
- compromissos assumidos;
- objetivos internos ativos.

## Workspace global

Estrutura de curta duração com capacidade limitada. Recebe apenas itens priorizados. Cada item contém conteúdo, fonte, confiança, saliência, idade e justificativa de seleção.

## Atenção

Calcula saliência a partir de:

- novidade;
- surpresa preditiva;
- repetição;
- conflito;
- menção direta;
- relevância para objetivo;
- risco;
- oportunidade de aprendizagem;
- custo de ignorar.

## Curiosidade

Gera perguntas quando:

- a incerteza é relevante;
- uma confirmação produziria ganho informacional;
- uma hipótese aparece repetidamente;
- há contradição;
- falta nome para um padrão estável.

## Metacognição

Antes de afirmar ou sugerir, avalia:

- o que sustenta a hipótese;
- quão confiável é;
- que alternativas existem;
- o que poderia refutá-la;
- se perguntar é melhor que afirmar;
- se deve permanecer em silêncio.

## Continuidade temporal

O agente deve distinguir:

- estado atual;
- experiência passada;
- previsão;
- intenção;
- fato confirmado;
- hipótese;
- memória reconstruída.

## Critério de eu funcional

Existe um eu funcional quando o sistema utiliza seu modelo de si de forma causal para interpretar percepções, controlar ações, explicar limitações e atualizar sua história.

## Cognição sob observabilidade parcial

O sistema deve raciocinar explicitamente sobre o que consegue ou não observar.

A perda de uma modalidade deve produzir:

- atualização de capacidades no modelo de si;
- redução seletiva de confiança;
- alteração do orçamento de atenção;
- bloqueio de inferências que exigem a fonte;
- preservação de memórias anteriores;
- busca de fontes substitutas;
- explicação da limitação.

O retorno ou adição de uma modalidade inicia calibração e aprendizagem antes de influenciar crenças consolidadas.
